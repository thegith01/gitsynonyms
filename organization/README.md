# 组织架构

本目录是依据 [`../DIRECTIVE.md`](../DIRECTIVE.md) 制定的**具体组织规章制度**，
负责展开部门设置、职责分工、内部流程、接口和实施细则。`DIRECTIVE.md` 是规定根本
层级、权责原则和不可违背约束的**宪法性最高指示**；本目录不得与之冲突。

授权范围内调整部门内部设置、职责细节或流程时，修订本目录及相关实施文件即可；
只有改变根本层级、授权边界或宪法性原则时，才需要总控同步修订 `DIRECTIVE.md`。

## 编制层级

职能层级：`部 → 司 → 处 → 科 → 组`；区域层级：`省 → 市 → 县 → 乡 → 村`。
**模块1、模块2、模块3 为部级单位**，司归部管辖，处归司、科归处、组归科；
不得越级、不得跨部挂靠（最高指示 2.1）。组为限期专项编制，不持有常设登记表。

## 职责接口

- **资源与巡检部**归口资源获取分析司与定期巡检司的编制与接口，不干预巡检判定。
- **资源获取分析司**维护资源清单、采集器映射与资源变化；不负责视频字幕刻录。
- 信息差公示处是资源获取分析司内部的研究与发布单元；职责、边界和实现状态见
  [`resource-acquisition-analysis.md`](resource-acquisition-analysis.md)。
- **定期巡检司**负责巡检制度、最小可巡检单元、证据与异常闭环。
- **模块1：情报与素材部**负责最小间隔监测、事件归纳与素材获取，向模块2交付
  事件结论与选定素材；不得刻录或发布。制度见
  [`module-1-intelligence.md`](module-1-intelligence.md)。
- **模块2：视频处理部**只接收上游已经选定的视频和字幕任务；不得自行替代上游
  选择来源、判定资源重要性或更改巡检结论。
- **ASR处**与**翻译处**隶属字幕制作司，分别负责“语音→英文逐词文本”和
  “英文→简体中文”的研究、打分与执行；两处的排名数据在
  `docs/engines/data/asr.json` 与 `translation.json`，制度见
  [`module-2-asr-office.md`](module-2-asr-office.md)、
  [`module-2-translation-office.md`](module-2-translation-office.md)。
- **语音制作司**下辖语音刻录处与语音克隆处：前者用音色库配音并按字幕时间轴混音，
  后者只在书面授权下复刻特定人音色。制度见
  [`module-2-voice-production.md`](module-2-voice-production.md)。
- 模块2其余处科及精度、画面处理要求，见
  [`module-2-video-processing.md`](module-2-video-processing.md)。
- **模块3：发布与治理部**下辖资源上传司、发布后处理司、PDCA司与监察司，负责
  多平台上传、发布后整改、流程优化与全流程监察；是发布侧唯一出口。制度见
  [`module-3-publishing.md`](module-3-publishing.md)。
- **监察司**独立于被监督对象，只向总控报告，不参与上传、整改与刻录。

## 规章与实现状态

本目录中的组织职责规定与代码实现状态是两类事实，不代表其中列出的每项制度都已
自动化。模块2的职责映射、当前代码位置和未完成要求必须分开说明；不得仅凭组织规章
或架构登记宣称功能已上线。
