GITSYNONYMS · FLOW WORKSPACE

流程编排

像 n8n 一样管理多条流程：每条流程单独选择模块、拖动排序、填写参数，命令计划实时更新。所有本机 Python 步骤统一通过 Anaconda a 环境执行；页面只生成命令，不执行、不上传，也不保存令牌。

WORKFLOWS

流程工作区

每个流程都有自己的节点链和参数；切换标签即可独立编排，互不影响。

CONTEXT

流程参数

参数属于当前流程；切换流程后会使用该流程自己的值。

本机命令会先定义 $py 并检查解释器是否存在。
高级参数（标题 / 日期 / 源片直链）

重刻时 source_url 留空会使用 workflow 默认示例地址；非示例视频请显式填写，避免取错素材。

MODULES

模块库

点击模块即可插入当前流程；内置模块可用“另存”克隆成可编辑模块。

CANVAS

执行链

从上到下执行；拖动节点或使用箭头调整顺序，关闭开关可临时跳过该节点。

RUNBOOK

命令计划

添加节点后生成对应命令。

GUARDRAILS

编排边界

完整规则
  • 每条流程独立流程标签之间互不影响；可复制流程后只改一个节点做对比，也可用模板快速创建新流程。
  • Anaconda 环境所有本机 Python 步骤都通过流程参数里的 Anaconda a 解释器执行，不调用系统 python。
  • 模块可重复同一模块可以多次加入同一条流程，例如先探测再重试；重复节点会按画布顺序执行。
  • 执行边界页面只生成 PowerShell 与 gh 命令，不在浏览器执行；跑云端步骤前请确认 gh 已登录且有仓库权限。
  • 自定义模块只保存在当前浏览器与导出的 JSON 中，不改写仓库文件；分享链接会携带流程用到的自定义模块。

TEMPLATES

从模板创建流程

“新建流程”会保留当前工作区；也可以直接替换当前流程的节点。

MODULE EDITOR

新建自定义模块

自定义模块只保存在浏览器与导出的 JSON 中；内置模块可用“另存”克隆后修改。
